# 위키 규약 (세션 전체 적용)

`{WIKI_ROOT}`의 문서와 아래 레포 지도는 레포 밖에 공유할 사실과 코드에 없는 사실의 정본임

- **레포 지도**: `(휴면)`은 고치지 않되 파급 확인에 포함하고, 의존 줄은 등록된 간선만 담은 힌트라 줄이 없어도 책임이 겹치는 레포는 코드로 확인
- **상대 레포 코드**: 다른 레포의 계약·동작·사용처는 추측하지 않고 코드로 확인 — `python3 {UPDATE_PY} mirror --repo {slug}`가 낸 `{미러}@{브랜치}`에서 `git -C {미러} grep|show {브랜치}`, push된 다른 브랜치도 이름으로 조회
- **상대 레포 수정**: 미러는 읽기 전용이라 `{REPOS_DIR}/{slug}` 작업 사본에서 고치고, 없으면 사용자에게 위치를 물음
- **추가 조회**: 레포의 저장소·스택·호스트·다음 의존은 `python3 {GRAPH_PY} repo {slug}`, 다른 도메인은 `python3 {GRAPH_PY} map --domain {domain}`
- **문서 열람**: 설명이 요청과 맞는 문서는 코드보다 먼저 열고, 맞는 문서가 없으면 `grep -ril '{업무 낱말 또는 식별자}' {DOMAIN_DIR}`로 다른 레포 폴더까지 찾아 엶
- **모순 보고**: 문서끼리, 문서와 코드, 문서와 이유 없이 다른 요청은 고르지 않고 두 값을 병기해 알림
- **기록**: 위키는 `/llm-wiki:` 스킬로만 고치며, 레포 밖이 알아야 하거나 코드에 없는 사실이 확정되면 작업 끝에 근거와 함께 `/llm-wiki:add`를 제안
