# 위키 규약 (세션 전체 적용)

`{WIKI_ROOT}`의 문서는 코드에 없는 사실의 정본입니다. 아래 도메인 목록·의존 간선, 도메인 `index.md` 본문과 목록(도메인 루트 + 현재 레포)에서 요청에 걸리는 문서를 골라 읽고 진행하며, 사용자가 세션에서 다르게 지시하면 그 지시가 우선합니다.

- **문서 우선**: 사전 지식과 문서가 어긋나면 문서를 믿되, 사용자가 개정·재논의·정정의 맥락을 밝히면 그 설명이 문서를 이김 — 맥락 없는 이견은 문서를 이기지 못하고 모순 보고로 감
- **여는 기준**: 목록의 설명이 이번 요청의 작업과 맞는 문서는 코드를 읽기 전에 열고, 걸리는 문서가 없으면 열지 않음
- **도메인 지도**: `index.md` 본문은 레포 구성·역인덱스라 코드 변경 시 어느 레포가 그 업무를 맡는지 찾을 때 먼저 봄
- **의존 간선**: 주입된 간선에서 현재 레포를 `to`로 가진 `from` 레포가 변경의 파급 대상이며, 다른 도메인 레포이면 그 도메인 `index.md`를 Read하고 `python3 {CATALOG_PY} --root {WIKI_ROOT}/knowledge/{domain}/{slug}`로 목록을 본 뒤 필요한 문서만 엶 — 간선의 추가·삭제도 스킬로만 함
- **범위 순서**: 같은 주제가 도메인 루트와 레포 폴더에 둘 다 있으면 도메인 루트를 먼저 읽고 레포 문서는 그 위에서 좁힌 부분만 읽음
- **낡음 표시**: 목록의 `!` 문서는 마지막 확인이 180일을 넘은 것이라 코드로 대조한 뒤 사용함
- **모순 보고**: 문서끼리 또는 문서와 코드가 어긋나면 임의로 고르지 않고 두 값을 병기해 사용자에게 알림
- **직접 수정 금지**: 위키는 스킬로만 고침 — 자료·대화에서 정한 사실은 `/llm-wiki:add`, 등록 레포의 머지 반영은 `/llm-wiki:update`, 조각·중복·낡음·규약 위반 정리는 `/llm-wiki:audit`, 위키 저장소 생성은 `/llm-wiki:init`, 레포 등록·도메인 이동은 `/llm-wiki:register`
- **기록 제안**: 대화에서 정책·결정·함정처럼 코드에 없는 사실이 확정되면 그 값을 정한 근거와 함께 작업 끝에 `/llm-wiki:add`를 제안하며 임의로 기록하지 않음
- **커서 불변**: `state/`의 커서는 `/llm-wiki:update`만 전진시키며 손으로 고치지 않음
