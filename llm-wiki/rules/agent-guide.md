# 위키 규약 (세션 전체 적용)

`{WIKI_ROOT}`의 문서는 코드에 없는 사실의 정본입니다. 아래 도메인 목록·역인덱스·의존 간선과 목록(도메인 루트 + 현재 레포)에서 요청에 걸리는 문서를 골라 읽고 진행하며, 사용자가 세션에서 다르게 지시하면 그 지시가 우선합니다.

- **문서 우선**: 사전 지식과 문서가 어긋나면 문서를 믿되, 사용자가 개정·재논의·정정의 맥락을 밝히면 그 설명이 문서를 이김 — 맥락 없는 이견은 문서를 이기지 못하고 모순 보고로 감
- **여는 기준**: 목록의 설명이 이번 요청의 작업과 맞는 문서는 코드를 읽기 전에 열고, 걸리는 문서가 없으면 열지 않음
- **역인덱스**: 요청의 업무 낱말이 역인덱스 행에 있으면 그 행의 레포 집합이 수정·검토 대상이고, 없으면 도메인 목록의 영역 이름이 걸리는 도메인을 `python3 {GRAPH_PY} map --domain {domain} --wiki {WIKI_ROOT}`로 본 뒤 그 레포 문서를 `python3 {CATALOG_PY} --root {WIKI_ROOT}/knowledge/{domain}/{slug}`로 봄 — 레포 밖 세션도 같음
- **선행 조건**: 현재 레포에서 HTTP 호출·라이브러리 import·메시지 소비·타 레포 데이터 조회를 더하거나 바꾸면 `이 레포가 의존` 간선의 `to` 레포 코드를 인접 좌표의 로컬 경로(없으면 `git clone --depth 1 https://{remote}.git`을 스크래치에)로 열어 계약 대응 여부를 대조하고, 대응이 없으면 선대응 필요로 보고
- **파급 대상**: 현재 레포의 공개 계약(컨트롤러·공용 라이브러리 심볼·발행 메시지·공유 스키마)이 바뀌면 `이 레포에 의존` 간선마다 `kind`·`note` 식별자와 대조하고 걸리면 `from` 레포 코드에서 소비 여부를 확인해 리뷰·보고에 파급을 명시 — 타 도메인 `from`은 도메인 이름을 함께 적고 `!` 간선은 대조 전 최신 여부를 재확인
- **범위 순서**: 같은 주제가 도메인 루트와 레포 폴더에 둘 다 있으면 도메인 루트를 먼저 읽고 레포 문서는 그 위에서 좁힌 부분만 읽음
- **낡음 표시**: 목록의 `!` 문서는 마지막 확인이 180일을 넘은 것이라 코드로 대조한 뒤 사용함
- **모순 보고**: 문서끼리 또는 문서와 코드가 어긋나면 임의로 고르지 않고 두 값을 병기해 사용자에게 알림
- **직접 수정 금지**: 위키는 스킬로만 고침 — 자료·대화에서 정한 사실은 `/llm-wiki:add`, 등록 레포의 머지 반영은 `/llm-wiki:update`, 조각·중복·낡음·규약 위반 정리는 `/llm-wiki:audit`, 위키 저장소 생성은 `/llm-wiki:init`, 레포 등록·도메인 이동은 `/llm-wiki:register` — 노드·간선은 register·add·update만 고치고 `state/`의 커서는 update만 전진시킴
- **기록 제안**: 대화에서 정책·결정·함정처럼 코드에 없는 사실이 확정되면 그 값을 정한 근거와 함께 작업 끝에 `/llm-wiki:add`를 제안하며 임의로 기록하지 않음
