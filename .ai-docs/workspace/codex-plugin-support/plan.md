# Claude Code·Codex 공용 플러그인 지원

## 의도

- **왜**: 기존 Claude Code 플러그인 4종을 Codex에서도 사용하고 공통 구현을 한 곳에서 유지한다.
- **누가**: 개인 마켓플레이스 사용자와 이를 미러링하는 팀 사용자.
- **완료**: 개인 원본 구현·검증, 4종·9개 스킬 전체 적용, 팀 마켓플레이스 이식·재검증과 설치 안내를 완료한다. 자동 검사와 실제 클라이언트 검증을 구분한다.

## 확정 결정 (사용자 확인 2026-11-05)

- 개인 원본에서 구현·테스트한 후 전체 적용하고 대상 마켓플레이스로 이식한다. 사용자가 제시된 계획을 승인하고 진행을 요청했다.
- Claude Code 동작을 유지하며 Codex 데스크톱과 CLI를 지원 대상으로 삼는다. Cloud·웹과 업무 저장소 일괄 설정 배포는 이번 범위 밖이다.
- 플러그인 이름·공통 스킬·업무 규약은 유지하며 패키징과 환경별 실행 연결을 추가한다.
- 계획 승인과 구현 승인을 구분하는 제품 동작, 위키 명시 호출 제한, 외부 게시 승인 절차를 보존한다.
- 현재 작업 자체는 사용자의 계획 진행 지시에 따라 구현·검증·이식까지 수행한다.

## 배경

- 개인 origin/main 658cea2가 최신 기준이다. 기존 로컬 main의 고유 계획 커밋은 그대로 보존하고 별도 작업 브랜치에서 진행한다.
- 원본 플러그인 버전은 작성 규칙 4.2.0, PR 3.2.0, 계획 3.5.0, 위키 0.11.0이다.
- 기존 작성 규칙 평가 입력은 .ai-docs/workspace/codex-better-communication/cases.json에 있다. 기존 결과는 Claude 평가이므로 Codex 통과 증거로 사용하지 않는다.

## 특이 사항

- 테스트는 임시 저장소·별도 설치 상태를 사용한다. 실제 위키를 테스트 초기화 대상으로 사용하지 않는다.
- 원격 쓰기 검증은 전용 테스트 대상에서 수행하며, 모의 응답 성공을 실제 게시 성공으로 보고하지 않는다.
- 각 검증은 클라이언트 버전·모델·입력·결과와 미검증 범위를 기록한다.
- 원본 공통 결함은 원본에서 먼저 수정한 뒤 다시 이식한다. 대상 호스트 설정은 대상에서만 유지한다.
