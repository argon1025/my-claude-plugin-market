# PR 병합 조건

현재 PR 원본에서 저장소, 대상 브랜치, base·head와 실제 diff를 고정한다. 요청과 현재 계획이 지정한 병합 전 조건, 같은 head를 검토한 기록, 검증 결과, 지적·해결 근거, 저장소의 필수 승인 규칙·현재 승인을 읽는다.

| 조건 | 확인할 사실 |
| --- | --- |
| 독립 리뷰 | 구현과 독립된 리뷰어가 현재 head와 대상 변경 범위를 검토해 통과시켰다. |
| 사전 검증 | 계획에서 병합 전에 요구한 검증이 해당 변경 판본에서 모두 통과했다. 병합 후에만 가능한 검증은 별도 대기로 남긴다. |
| 차단 지적 | 현재 변경에 남은 차단 지적이 없다. 지적이 있었다면 처리와 재검토 근거를 확인한다. |
| 필수 승인 | 현재 대상 브랜치에 호스트가 요구하는 승인 조건을 모두 만족한다. 철회·무효화된 승인은 제외한다. |

각 조건에 충족·불충족·미확인과 원본 위치를 붙인다. 요구 검증·승인이 0건이면 그 근거로 충족을 표시한다. 하나라도 불충족이면 병합 불가, 불충족이 없어도 근거가 부족하면 미확인이다. 네 조건이 모두 충족되고 PR이 열려 있고 호스트가 병합 가능한 상태여야 병합 가능으로 반환한다. head·대상·diff나 근거가 바뀌면 새 판본에 대해 대조한다.
