# 데이터 변경 체크리스트

사람이 실행할 SQL처럼 운영 데이터를 직접 바꾸는 산출물을 쓰거나 리뷰할 때 봅니다.

- **사전 상태 확인**: 실행 전에 지금 상태를 보는 조회와 기대값을 함께 둠. 기대와 다르면 멈추라고 적음. 환경(개발, QA, 상용)마다 이미 적용된 정도가 다를 수 있다고 가정함
- **다시 실행해도 안전함**: 이미 있는 행을 다시 넣지 않고, 같은 스크립트를 두 번 실행해도 결과가 같게 씀
- **되돌리기**: 되돌리는 스크립트는 고정값이 아니라 실행 전에 보관한 값으로 복원함. 실행 전 값을 보관하는 단계를 둠
- **순서와 번호**: 노출 순서나 일련번호는 고정값으로 넣지 않고 기존 행을 기준으로 한 상대값으로 정함
- **사후 확인**: 실행 뒤 기대 결과를 보는 조회를 두고, 반영을 알릴 때 그 출력을 함께 남기게 함
- **코드와의 순서**: 코드 배포와 데이터 반영 가운데 무엇이 먼저여야 하는지, 어긋나면 무엇이 깨지는지를 적음
