단건은 지정된 원래 문의와 정정만, 정기 조회는 [운영 환경](../../references/host.md#운영-환경-선택과-인계)의 대기 문의와 대상 브랜치의 실제 병합·연결된 PR을 모두 읽는다. 누가 병합했는지와 관계없이 대상에 넣는다. 새 머지·담당자 알림이 0건이어도 대기 문의를 확인한다.

문의마다 요청한 종료 지점과 필요한 서비스·환경·판본을 찾는다. PR 검토라면 해당 head의 검토 결과, 병합이면 실제 병합 판본, QA 가능이면 필요한 서비스 버전 조합의 대상 환경 배포, 기능 확인이면 해당 조건의 현재 판본 독립 판정과 실행 근거를 대조한다. 한 PR이나 이슈에 여러 문의가 연결돼 있으면 각 문의가 기다리는 결과를 따로 본다.

원래 대화의 기존 안내와 비교해 대화·요청 메시지, 아직 안내할 결과·판본·근거를 반환한다. 이미 안내했으면 메시지 위치를, 대기 중이면 빠진 조건을 반환한다. 조회 실패는 미확인으로 남기고 발송하지 않는다.
