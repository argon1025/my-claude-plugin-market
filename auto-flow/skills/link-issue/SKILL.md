원래 요청·정정의 위치와 시점, 대상 프로젝트, 요청한 종료 조건과 알려진 이슈를 읽는다. 사람이 선별한 원문으로도 직접 시작한다. [운영 환경과 인계](../../references/host.md#운영-환경-선택과-인계)에서 추적 대상·라벨 정책을 확인한다.

1. 원래 대화 링크와 조건으로 열린 이슈와 닫힌 이슈를 검색한다. 후보의 원문·대상·완료 조건을 대조한다. 같은 조건의 재제보라면 닫힌 이슈를 사용한다. 후보가 여럿이고 근거로 구별할 수 없으면 후보와 필요한 확인을 반환한다.
2. 같은 이슈가 없음을 확인하면 프로젝트 필수 필드와 요청·완료 조건, 원래 대화 링크를 담아 생성한다. 기존 이슈면 빠진 원문 링크만 보완하고, 추적 대상이면 정책에 지정된 라벨도 확인한다. 기존 라벨·본문·계획을 보존한다. 단순 문의나 조사 요청을 자동 개발 대상으로 만들지 않는다.
3. 쓰기 직전 후보를 재조회하고 생성·연결·라벨 결과를 각각 확인한다. 생성 응답이 끊기면 원문 링크와 조건으로 실제 이슈를 찾는다. 성공 여부가 모호하면 생성 재시도를 보류한다. 이슈 키·상태·원문 위치와 새로 반영한 항목을 반환한다. 재개 전환과 대화 전송은 수행하지 않는다.
