---
name: check-deployment
description: 서비스별 필요 변경이 지정 환경에 실제 배포됐는지 조회하거나 사람의 배포 확인 회신을 연결할 때 사용한다.
---

서비스·대상 환경·필요 변경(PR·커밋 또는 포함 버전), 적용 조건과 프로젝트의 [환경별 확인 경로](../../references/host.md#운영-환경-선택과-인계)를 읽는다. 어느 서비스가 그 환경을 필요로 하는지부터 특정한다.

- 조회 가능하면 해당 서비스·환경에서 현재 실행되는 버전에 요청한 변경이 포함됐는지 배포 기록으로 대조한다. 빌드 성공이나 병합만 확인되면 배포 미확인이다.
- 사람의 확인이 필요하면 이슈 조건에 연결된 원래 요청과 대화, 이미 온 회신부터 읽는다. 확인 요청이 허용된 경우 같은 서비스·환경·버전에 이미 요청했다면 그 위치에서 기다린다. 없으면 한 번 요청하고 이슈 조건에 대화를 연결한다. 회신·링크만 누락된 경우 이미 한 요청을 반복하지 않는다. 조회만 맡겼으면 필요한 연락처와 질문을 반환한다.
- 서비스별 배포 확인·대기·미확인, 환경·실제 판본·근거 또는 요청 위치를 반환한다. 변경되지 않은 서비스의 유효한 근거는 재사용하고 바뀐 서비스만 다시 확인한다. 배포 실행이나 기능 동작 판정까지 수행하지 않는다.
