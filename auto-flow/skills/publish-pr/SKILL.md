---
name: publish-pr
description: 준비된 변경을 지정한 대상 브랜치로 제안하거나, 준비된 수정 커밋을 기존 PR의 소스 브랜치에 게시할 때 사용한다.
---

[판본과 PR 호스트 접근 기준](../../references/host.md)에 따라 대상·소스 저장소와 브랜치, 게시할 판본, 관련 Jira 조건·계획과 제공된 검증 근거를 확인한다. 실제 확인한 범위만 PR에 적는다. 로컬 작업 사본을 받았다면 게시할 차이를 특정해 그 변경만 커밋으로 준비한다. 불분명한 변경은 섞지 않는다.

- **새 PR.** 원격 소스 브랜치와 같은 소스·대상의 열린 PR을 조회한다. 같은 변경을 제안하는 열린 PR이 있으면 재사용한다. 과거에 닫히거나 병합된 PR의 브랜치를 새 변경에 재사용하는 경우에는 지정한 커밋을 게시하고 새 PR을 만든다. 같은 브랜치의 열린 PR이 다른 작업을 담고 있으면 푸시 전에 대상 충돌을 반환한다.
- **기존 PR 갱신.** 지정한 PR의 상태, 실제 소스 저장소·브랜치와 현재 head를 읽는다. 준비한 수정이 이미 게시됐으면 위치와 PR 상태를 반환한다. 닫히거나 병합된 PR에 새 수정본을 요청받으면 해당 상태를 반환하고 멈춘다. 열린 PR에는 다른 사람이 올린 커밋을 덮지 않고 남은 수정만 게시한다. 판본이 갈라져 안전하게 반영할 수 없으면 양쪽 SHA와 보류 사유를 반환한다.
- 쓰기 응답이 끊기면 원격 브랜치와 같은 소스·대상의 PR 이력에서 요청한 게시를 찾는다. 커밋과 PR 생성 이력이 일치하면 그사이 닫혔더라도 기존 PR의 위치·상태를 반환한다. 푸시만 반영됐으면 PR 생성만 처리한다.

호스트에서 대상 브랜치·PR 링크·실제 head를 다시 읽고 요청한 커밋이 포함됐는지와 남은 일을 반환한다. 병합·리뷰·상태 전환으로 진행하지 않는다.
