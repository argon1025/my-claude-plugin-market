---

PR과 대상 스레드, 판정 및 근거를 받아 [PR 호스트 접근과 쓰기 복구](../../references/host.md) 기준으로 다음을 확인한다.

1. 원래 지적과 기존 답글, PR의 실제 head를 읽는다. 수정 완료를 알릴 때는 수정 판본이 해당 PR에 포함되고 현재 코드에도 해결 내용이 남아 있는지 확인한다. 로컬에만 있거나 실제 게시 여부를 확인할 수 없으면 해당 회신은 보류한다.
2. 각 스레드에서 같은 지적에 같은 판정·수정 판본 또는 여전히 유효한 해결 위치·근거를 알린 답글을 찾는다. 표현이나 작성자가 달라도 같은 결과이면 기존 답글 위치를 반환한다. 다른 스레드나 과거 판본의 다른 결론은 전송 근거가 될 수 없다.
3. 빠진 결과만 해당 스레드에 답한다. 수용·수정이면 게시된 수정 판본과 위치, 이미 해결이면 확인한 코드 위치, 이견이면 판정의 근거를 담는다. 쓰기 응답이 유실되면 스레드를 다시 조회해 실제 답글 위치를 확인한다. 전송 여부가 불분명하면 미확인으로 반환한다.

스레드마다 기존·신규 답글 위치 또는 보류 사유를 반환한다. 코드 수정, 테스트, PR 게시, 재리뷰, 스레드 종료를 반복하거나 이어서 실행하지 않는다.
