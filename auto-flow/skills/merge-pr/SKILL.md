description: 요청과 계획에 포함된 PR 병합을 실행하거나 지정된 사람에게 해당 커밋의 병합을 요청할 때 사용한다.
---

PR·대상 브랜치·지정 head와 요청·계획의 병합 범위, [운영 환경의 병합 방식](../../references/host.md#운영-환경-선택과-인계)을 확인한다. 실제 PR이 이미 병합됐으면 누가 수행했든 호스트의 대상·병합된 소스 판본·결과 커밋·근거를 반환한다. 다른 head가 병합됐다면 두 판본을 구분해 그 버전의 검증이 남았는지 밝힌다.

1. 열려 있는 PR은 쓰기 직전에 [병합 조건](../../references/merge-conditions.md) 네 가지와 범위·권한을 다시 확인한다. 앞선 판정서 없이도 원본으로 확인한다. 고정해서 맡긴 head가 바뀌면 기존 승인을 새 head에 적용하지 않는다.
2. 자동 방식은 검토한 대상·head를 호스트가 보장하는 판본 조건으로 병합한다. 그 결합이나 권한을 확인할 수 없으면 미실행으로 반환한다. 충돌이나 승인 철회가 있으면 원본을 다시 판정한다. 사람 방식은 기존 요청을 조회하고 같은 커밋에 아직 요청하지 않았을 때만 지정 수신처에 PR·head·근거를 보낸다.
3. 응답이 끊기면 PR의 실제 병합 상태와 해당 커밋의 기존 요청을 먼저 확인한다. 처리 중이거나 판별할 수 없으면 위치와 대기 이유를 반환한다. 사람에게 전달된 상태와 실제 병합을 구분하고, 확인한 판본과 위치를 반환한다. 배포·상태 전환·결과 안내는 이어서 실행하지 않는다.
