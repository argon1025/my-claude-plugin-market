레포, 확인할 조건·범위와 환경을 읽고 [판본과 인계 기준](../../references/host.md#개발-작업의-판본과-인계)으로 테스트할 실제 파일을 특정한다. 다른 판본이 체크아웃돼 있으면 기존 작업을 보존하면서 지정 판본을 사용한다.

1. 저장소에서 해당 조건을 다루는 테스트와 실행 명령을 확인한다. 실행 전 판본과 환경(런타임·의존 버전, 모의 의존성 등 결과에 영향을 주는 부분)을 기록하고 지정 범위를 실제로 실행한다.
2. 조건별 **통과 / 실패 / 미실행**을 명령, 종료 상태, 관찰된 출력이나 로그 위치와 연결한다. 환경이나 테스트가 없으면 미실행 사유와 재개에 필요한 것을 적는다. 통과한 테스트가 다루지 않은 입력·연동은 미확인으로 둔다. 실행 중 입력 판본이 바뀌면 어느 결과가 유효한지 밝힌다.
3. 실패한 코드·테스트를 고치거나 PR을 게시하지 않고 반환한다. 기존 실행 결과의 게시만 요청받았다면 같은 판본의 근거와 목적지의 기존 링크를 확인한 뒤 누락된 연결만 추가한다.
