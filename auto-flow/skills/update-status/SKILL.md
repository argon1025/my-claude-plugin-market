---

이슈·현재 상태와 계획 판본, 종료 지점, 조건별 독립 판정과 그 판본, 필요한 병합·배포 사실을 읽는다. [운영 환경과 인계](../../references/host.md#운영-환경-선택과-인계)에서 해당 프로젝트의 전환 기준과 이슈에서 허용된 전환을 확인한다.

판정이 현재 조건과 버전에 적용되는지 대조한다. 필요한 QA 판정이 없으면 모든 PR이 병합됐어도 완료 전환을 기다린다. SQL 작성·검토가 종료 지점이면 같은 SQL 판본의 충족 판정을 쓰며 DB 실행을 요구하지 않는다. 닫힌 이슈의 같은 조건에서 실패가 다시 확인되면 재개 전환의 근거와 가능 여부를 확인한다.

근거가 정한 도착 상태와 현재 상태가 같으면 기존 상태·이력을 반환한다. 허용된 전환만 현재 상태에서 한 번 수행하고 실제 상태와 전환 이력을 확인한다. 응답 유실·중간 수동 변경 시 이력을 확인해 현재 판본에서 필요한 전환만 판단한다. 적용한 전환 또는 대기 이유, 실제 상태·판본·근거를 반환한다.
