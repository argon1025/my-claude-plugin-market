description: 지정한 화면·API·업무 진입점으로 시나리오를 실제 실행하고 환경, 서비스 판본, 관찰값과 증거 위치를 반환한다.
---

요청에서 확인할 조건, 진입점, 입력·행동, 기대 결과와 필요한 환경을 읽는다. Jira 계획이 있으면 해당 조건 번호를 유지한다. 특정 배포 환경이 조건이면 그 환경의 실행 판본을 확인한다. 로컬 실연동이 허용되면 실제로 연결한 구성 요소와 외부 대역을 밝힌다.

1. 실행할 서비스별 커밋·빌드 또는 배포 식별자와 실제 환경을 확인한다. 작업 사본은 [판본 확인 기준](../../references/host.md#개발-작업의-판본과-인계)을 따른다. 확인하지 못한 판본은 그대로 표시한다.
2. 요청한 입력을 지정 진입점으로 실행한다. 화면에서 실응답이 표시되는 조건이면 **같은 행동**의 요청·응답과 화면 결과를 실행 시각, 요청 ID, 브라우저 추적 등으로 연결한다. 실제 연동, 목업, API 단독을 구성 요소와 함께 표시한다.
3. 조건마다 환경·판본·입력, 기대 결과와 실제 관찰, 증거를 다시 열 위치를 반환한다. 관찰한 실패에는 차이가 처음 나타난 지점을, 실행하지 못한 경로에는 필요한 환경·판본·관찰을 남긴다. 독립적으로 실행 가능한 부분은 그 범위까지 확인한다. 제품 코드 수정이나 이슈 완료 판정은 별도 요청의 책임이다.
