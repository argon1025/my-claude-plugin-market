---
name: review-code
description: 기존 PR의 코드 결함을 독립 리뷰하거나 수정본의 최신 head와 이전 지적을 대조해 재리뷰할 때 사용한다.
---

PR 하나만 받아도 [호스트 접근 기준](../../references/host.md)으로 대상 브랜치, 실제 base·head, diff와 적용할 계약을 찾는다. 구현자가 남긴 설명과 테스트 통과는 검토할 근거다. 자신의 수정에 대한 자체 점검만 가능하다면 독립 리뷰 통과로 기록하지 않는다.

1. 지정한 커밋을 고정하고 대상 브랜치와의 차이에서 바뀐 진입점·호출자·테스트를 따라간다. 실제 입력에서 기대와 다른 결과가 생기는 버그, 회귀, 계약 위반을 찾는다. 근거가 부족한 경로는 미확인 범위에 적는다.
2. 재리뷰할 때도 해당 PR의 최신 전체 diff를 본다. 이전 지적은 스레드별로 현재 위치와 대조하고 해결·잔존 여부 및 수정으로 새로 생긴 결함을 확인한다.
3. 검토 커밋과 조건, 통과 또는 지적을 반환한다. 지적에는 파일·줄이나 심볼, 입력·경로와 관찰 또는 재현 근거, 차단 여부를 적는다. 최신 판정을 내리거나 게시하기 직전에 대상 저장소·브랜치, head와 비교 범위를 다시 확인한다. base만 전진했다면 실제 diff와 적용 계약이 같은지 대조한다. 대상이나 head 또는 검토한 변경 범위가 달라졌으면 이전 판정이 적용되는 판본·대상과 새 비교 범위를 밝혀 반환한다.

리뷰만 요청받으면 결과를 반환하고 끝낸다. 게시 요청이 있으면 검토한 커밋을 지정해 기존 리뷰를 확인하고 누락된 결과만 남긴다. 코드 수정이나 병합은 하지 않는다.
