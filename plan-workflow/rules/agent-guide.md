# 작업 기록 규약 (세션 전체 적용)

작업 기록은 이슈마다 `{WORKSPACE_ROOT}/{이슈 키}/`에 둡니다. 스킬을 부르지 않아도 적용되며, 사용자가 세션에서 다르게 지시하면 그 지시가 우선합니다.

- **의도**: 코드를 고치기 전에 왜, 누가, 완료 조건을 확인함. 요청과 코드로 확정되지 않는 것만 묻고, 확인한 의도는 `plan.md`의 `의도`에 적음
- **지식**: 이 이슈가 끝난 뒤에도 다른 작업자의 행동을 바꿀 사실만 `feedback.md`에 적음
- **계획**: 요구가 불분명하거나 규모가 있는 작업, 이슈 여러 개를 함께 다루는 작업은 `{PLUGIN_NAME}`의 planning 스킬로 진행함
- **폴더**: 폴더 이름은 이슈 키이고, 이슈 키가 없는 작업은 주제의 kebab-case 이름을 씀. 같은 키의 폴더가 있으면 이어 씀
- **형식**: 첫 기록 전에 `{PLUGIN_ROOT}/references/record-format.md`를 읽고, `plan.md`를 쓰기 전에 `{PLUGIN_ROOT}/references/plan-format.md`를 읽음
