# plan.md 계획 형식

세션 `## 현재 워크스페이스` 블록의 기록 폴더에 있는 `plan.md`의 절 구성과 순서입니다. 계획을 세우는 절차는 planning 스킬을, 기록 유형은 세션에 주입된 작업 기록 규약을 따릅니다. 스냅샷만 읽는 실행 에이전트가 기준이므로 모든 절은 대화 맥락 없이 읽힙니다.

## 절 순서

```
# {제목}

## 의도
## 배경          (선택)
## 확정 결정
## 외부 계약     (선택)
## 선행 읽기     (선택)
## 작업
## 커밋 분해
## 특이 사항
```

## 필수 절

- **`## 의도`**: 첫 절로 두고 인터뷰에서 확인한 목적·사용자·완료 조건을 `**왜**`·`**누가**`·`**완료**` 불릿으로 담음
- **`## 확정 결정`**: 제목에 `(사용자 확인 YYYY-MM-DD)`를 붙이고 직접 합의한 결정은 원문에 가깝게 적음. 위임 항목은 아래 구분을 따르며, 현재 코드의 동작이나 미승인 추천안을 사용자 결정으로 적지 않음
- **`## 작업`**: 파일별 `| 파일 | 변경 | 사다리 |` 표를 두고, 새 단위는 사다리 단과 ⑦ 판정 근거를 밝히며, 설계 결정과 근거는 표 아래 H3로 파일마다 나눠 적음
- **`## 커밋 분해`**: `| # | 범위 | 검증 |` 표로 커밋 순서와 범위, 커밋별 명령·기대 출력·통과 조건을 적음
- **`## 특이 사항`**: 범위 밖, 의도적 단순화의 한계와 업그레이드 조건, 후속 작업을 적고 해당 없으면 `없음`이라고 적음

### 위임된 판단

`## 확정 결정` 안에서 해당 항목에만 위임 범위·제약과 사용자 확인 근거를 적습니다. 별도 필수 절은 추가하지 않습니다.

- **계획 중 선택한 경우**: `위임에 따른 선택`임을 밝히고 에이전트가 고른 안과 근거를 적음. 위임받았다는 사실과 사용자가 구체적인 선택안을 직접 정했다는 주장을 구분함
- **실행자에게 남긴 경우**: 선택할 수 있는 대상, 지켜야 할 동작·외부 계약·검증 조건, 다시 물어야 할 경계를 적음. 이 범위 밖의 요구사항 결정까지 위임하지 않음
- **미결정과 구분**: 명시적 위임 없이 `알아서 구현`, `A 또는 B`, `추후 확정`을 적으면 최종 계획이 아님. 범위·제약이 명확한 승인된 재량은 미결정 요구사항으로 취급하지 않음

## 선택 절

있을 때만 두며 없으면 제목도 남기지 않습니다.

- **`## 배경`**: `## 의도`와 `## 확정 결정` 사이에 두고, 실행자가 같은 탐색을 되풀이하지 않도록 조사로 확인된 사실만 적음
- **`## 외부 계약`**: 검증된 API 형태·코드값·규격을 계획 안에 인라인으로 적어 실행자가 외부 문서를 다시 찾지 않게 함
- **`## 선행 읽기`**: 코드보다 먼저 읽을 문서를 경로와 읽을 이유 한 줄로 적으며, 손대는 파일을 다루는 문서와 관례·스타일 문서를 포함하고 세션에 주입된 사전 정보에서 찾은 문서는 새 세션에서도 열리도록 절대 경로로 적음

## 추가 절

- **제목**: 파일 끝에 `## 추가 계획 YYYY-MM-DD — {한 줄 계기}` 또는 `## Re-plan YYYY-MM-DD — {한 줄 계기}`로 덧붙이고 앞 절은 고치거나 지우지 않음
- **내부 구성**: 위와 같은 절을 H3(`### 의도`)로 같은 순서에 두고 해당 없는 절은 생략함
- **폐기 선언**: 앞 절의 결정이 무효가 되면 첫 불릿에 `폐기: {절 이름 또는 항목}`과 근거·대체 결정을 적고, 영향을 받는 계약·작업·검증도 함께 정리함
- **자기완결**: 앞 절과 겹치는 계약은 문서 안의 절 이름으로 참조하되 대화 참조는 쓰지 않음

## 금지

- **대화 참조**: `위에서 말한`·`논의한 대로`처럼 스냅샷 밖을 가리키는 표현
- **미결 문장**: 합의·명시적 위임 없이 남은 선택지와 `추후 확정`·`TBD` 같은 미정 표시
- **검증 없는 커밋 행**: 변경 서사만 있고 명령·통과 조건이 없는 커밋 분해 행
