# 실행 환경 연결

- **경로**: 이 스킬의 SKILL.md가 있는 폴더에서 ../../를 실제 경로로 해석한 값이 {PLUGIN_ROOT}다. 설치 캐시의 경로를 쓰며 소스 체크아웃이나 셸 환경변수 존재를 가정하지 않는다. 명령의 자리표시자는 실행 전에 치환하고 경로 인자는 따옴표로 감싼다.
- **질문**: Claude Code는 AskUserQuestion, Codex는 현재 세션에 노출된 질문 도구를 사용한다. 도구가 없으면 일반 메시지로 묻고 답을 기다린다. 질문·선택지 수는 실제 도구 한도에 맞춰 여러 라운드로 나누며, 자유 입력은 도구의 입력 기능을 사용한다. 답 없음은 승인이나 위임이 아니다.
- **파일 도구**: 본문의 Read·Write·Grep은 읽기·쓰기·검색 역할을 뜻한다. Claude Code에서는 해당 도구, Codex에서는 사용 가능한 읽기·검색 명령과 편집 도구를 사용한다. 긴 파일은 범위를 나눠 끝까지 읽고 잘린 출력을 전문으로 취급하지 않는다.
- **위임**: Claude Code에서는 Agent, Codex에서는 세션에 노출된 서브에이전트 도구를 사용한다. 도구 이름·모델 이름을 추측하지 않는다. 본문의 배치 상한과 실제 가용 동시 실행 수 중 작은 값을 지키고 남은 작업은 다음 배치로 넘긴다. 위임 도구가 없으면 필요한 위임을 수행할 수 없다고 보고하고 중단한다. 스킬에 직접 수행 조건이 명시된 경우에만 그 조건을 따른다.
- **호출 안내**: Claude Code의 /플러그인:스킬 표기는 Codex에서 명령으로 실행하지 않는다. Codex에서는 $ 선택기 또는 /skills에 실제 노출된 항목을 선택하도록 안내하고, 동명 스킬이면 현재 플러그인과 설치 경로로 구분한다.

계획 승인은 planning의 승인 질문에 사용자가 답한 것만 뜻한다. 계획 도구 호출(Codex의 update_plan 등)이나 계획 모드의 전환·종료를 승인으로 해석하지 않는다. 쓰기가 막힌 계획 모드에서는 분류표까지만 보이고 그 모드를 끝낸 뒤 이어 가며, 스스로 끝낼 수 없으면 쓰기 가능한 모드로 바꿔 달라고 알리고 기다린다.
