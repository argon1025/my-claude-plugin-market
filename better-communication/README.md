# better-communication

응답·진행 보고·PR 본문·문서를 간결하고 이해하기 쉬운 한국어로 작성하도록 돕는 플러그인입니다. 함께 개발하는 동료에게 설명하듯 결론부터 말하고, 구체적인 동작과 검증 상태를 자연스러운 문장으로 전달합니다.

## 설치

```
/plugin marketplace add argon1025/my-claude-plugin-market
/plugin install better-communication@my-claude-plugin-market
```

요구 사항은 `python3`입니다.

## 동작 방식

- **SessionStart**: [응답·문서 작성 규칙](./rules/agent-guide.md) 전문을 세션 컨텍스트에 주입합니다. startup·resume·clear·compact에서 다시 실행합니다.
- **UserPromptSubmit**: 세션 시작에 주입한 규칙을 가리키는 한 줄을 매 턴 추가합니다. 규칙 본문은 한 곳에서 관리합니다.

규칙 준수 여부를 자동으로 검사하지는 않습니다. 끄려면 `/plugin`에서 플러그인을 비활성화합니다.

## 작성 기준

- 질문에 먼저 답하고, 판단에 필요한 이유와 근거까지만 설명합니다.
- 일반 질문과 작업 보고는 짧은 답변을 기본으로 합니다. 자세한 설명을 요청하면 충분히 설명하고, 지정된 양식은 유지합니다.
- 명사형 종결·고정 보고 목차·모든 항목의 굵은 라벨을 강제하지 않습니다.
- 조건과 적용 대상, 실패와 미검증 상태는 줄이지 않습니다. 추상적인 이름보다 실제로 달라지는 동작을 설명합니다.
- 확인한 사실과 추천·미확인 사항을 구분합니다. 입력에 없는 계약을 만들거나 같은 결론과 후속 제안을 반복하지 않습니다.

예를 들어 `검증 일부 미완료로 종결 판단 보류` 대신 `단위 테스트는 통과했습니다. 빌드는 의존성을 내려받지 못해 확인하지 못했습니다.`라고 씁니다.

이 플러그인은 표현을 다룹니다. 요구사항을 하나씩 합의하고 승인받는 절차는 [plan-workflow](../plan-workflow/README.md)가 담당합니다. 사실 확인이나 요구사항 검토를 대신하지 않습니다.

## Codex 지원

[마켓플레이스 설치·검증 안내](../README.md#codex-설치)를 따릅니다. 공통 스킬과 규약을 사용하며, 이 플러그인은 스킬 없이 훅으로 작성 규칙을 주입합니다. 번들 훅이 있는 플러그인은 /hooks에서 검토·신뢰해야 세션 주입이 실행됩니다.
