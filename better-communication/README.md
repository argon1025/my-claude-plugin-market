# better-communication

사람이 읽을 산출물(최종 응답·PR 본문·문서)의 작성 규약을 세션에 자동 주입하는 플러그인입니다.

## 설치

```
/plugin marketplace add argon1025/my-claude-plugin-market
/plugin install better-communication@my-claude-plugin-market
```

요구 사항은 `python3`입니다.

## 동작 방식

- **SessionStart**: `rules/agent-guide.md` 전문을 세션 컨텍스트에 주입하며, matcher가 없어 startup·resume·clear·compact 모두에서 다시 실행되므로 컨텍스트 압축 뒤에도 규약이 유지됨
- **UserPromptSubmit**: 주입된 규약을 가리키는 한 줄 포인터(약 30토큰)를 매 턴 주입하며, 규칙을 재서술하지 않아 규약 수정 지점은 한 곳으로 유지됨

규약 준수 여부는 검사하지 않습니다. 끄려면 `/plugin`에서 플러그인을 비활성화합니다.

## 규약 요약

- **독자 기준**: 작업 세부를 모르는 상위 결정권자를 독자로 두고, 판단이나 다음 행동을 바꾸는 사실까지만 기술
- **보고 골격**: 목표 및 배경, 변경 및 결정 사항, 특이 사항, 검증 결과 및 효과 중 필요한 절만 순서대로 사용하며 짧은 답변에는 소제목 생략
- **항목 구조**: `**라벨**: 핵심 내용` 형태의 불릿을 명사형으로 종결하고, 부수 사실은 한 문장으로 결합
- **금지 사항**: 인사말·후속 제안·필러·헤징·도구 나레이션·이모지·비표준 약어 금지, 기술 식별자와 사용자 입력 언어는 원형 유지
- **예외**: 보안 경고, 비가역 작업 확인, 다단계 지시 등은 완전한 문장으로 작성
